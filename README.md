# CloudCleaner Demo Payments

A small synthetic payments proof-of-concept repository used by CloudCleaner demonstrations.

## Purpose

This repository intentionally contains ordinary application code, tests, branches, pull requests, and GitHub Actions configuration so CloudCleaner can inspect realistic-looking GitHub evidence without touching a real production system.

Owner: Hayden
Project: payments
Environment: dev

## Components

- `src/payments.py` — tiny payment-processing stub
- `tests/test_payments.py` — basic tests
- `.github/workflows/ci.yml` — continuous integration workflow

This project is synthetic and contains no real payment credentials or customer data.
